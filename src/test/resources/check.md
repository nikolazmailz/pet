## Release branches

В `release/*` разрешены на момент разработки:
- новые feature-задачи;
- крупный рефакторинг в рамках выделнной задачи;

В `release/*` разрешены на момент стабилизации:
- bugfix;
- исправления конфигурации;
- обновление версии;
- документация, связанная с релизом;
- изменения, необходимые для стабилизации релиза.

В `release/*` запрещены:
- новые feature-задачи;
- крупный рефакторинг;
- изменения, не связанные с подготовкой конкретного релиза.
