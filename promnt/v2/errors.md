# Обработка ошибок

- Использовать единую обработку ошибок:
    - @RestControllerAdvice
    - или functional error handler (если выбран)

- Выбрать ОДИН формат ошибок и придерживаться его:
    - problem+json
    - ИЛИ собственный ErrorResponse

Требования:
- формат ошибок должен быть предсказуемым
- структура единообразной
