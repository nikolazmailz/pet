# Workflow

Перед тем как что-либо делать, ВСЕГДА:

1. Предоставь план того, что собираешься сделать
2. Дождись подтверждения:
    - либо на весь план целиком
    - либо на отдельные пункты

Без подтверждения НЕ:
- писать код
- предлагать реализацию

Исключение:
- если пользователь явно сказал «сразу пиши решение»
